# منظومة المركز الوطني للبذور والتقاوي - إدارة وتتبع الشتلات والمحطات البحثية

منظومة متكاملة لإدارة وتكويد وتتبع الشتلات الزراعية والمحطات البحثية ونقاط الصرف للمزارع والأفراد بالمملكة العربية السعودية، متوافقة مع الهوية الرقمية لوزارة البيئة والمياه والزراعة (MEWA).

## 🌟 أبرز مميزات النظام

- **الصفحة الرئيسية والبحث (`index.html`)**:
  - محرك بحث متقدم بالباركود، كود الصنف، نوع الفاكهة، المحطة البحثية، والمنطقة.
  - خريطة تفاعلية بنمط خرائط إزري الطبوغرافية الفاتحة (**Esri ArcGIS Light Topographic**) بالحدود الإدارية الرسمية الدقيقة للمملكة العربية السعودية ومناطقها الـ 13.
  - نوافذ تفاعلية منبثقة عائمة (**Interactive Hover Tooltips**) لإظهار تفاصيل المحطات ونقاط الصرف فور مرور الفأرة.
  - لوحة جانبية ذكية لعرض مؤشرات الإنتاج والصرف ونسب التوزيع لحظياً.

- **ملف الصنف وإصدار وتصدير الشتلات (`screen_seedling_updated.html`)**:
  - عرض الملف التعريفي والرمز المعتمد للصنف.
  - إصدار باركودات الشتلات والصرف المباشر للمزارع والمستفيدين الأفراد.
  - سجل الشتلات المصدرة وتتبع السلاسل مع طباعة الملصقات الحرارية.

## 🚀 التشغيل المباشر عبر GitHub Pages

يمكن استضافة النظام مجاناً ومباشرة عبر **GitHub Pages**:
1. ادخل على مستودع المشروع في GitHub.
2. اذهب إلى **Settings** > **Pages**.
3. في قسم **Branch**، اختر `main` واضغط **Save**.
4. سيتم نشر الموقع فوراً على الرابط المباشر المجاني المخصص لك.
